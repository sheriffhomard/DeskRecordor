# Security

Please report security issues through
[GitHub's private vulnerability reporting](https://github.com/sheriffhomard/DeskRecordor/security/advisories/new)
when available, or contact the maintainers through the repository.

The application source currently contains no account, cloud upload, or
telemetry implementation. This statement is limited to this repository's
source; it is not an audit of Python, GTK, FFmpeg, desktop services, or the
operating system. The application uses local desktop and audio services and
stores recordings locally.
