# Landing-page content brief

This copy is a source for a future website, not a claim that planned features
are already available.

## Product

- **Name:** DeskRecordor
- **Slogan:** Your screen. Your voice. Nothing complicated.
- **Short description:** An early-stage Linux desktop recorder project for
  capturing a screen and microphone through a simple GTK interface.
- **Long description:** DeskRecordor aims to make basic screen-and-voice
  recording less complicated than a streaming or video-editing suite. It
  targets Debian desktops and is designed around local files and system
  capture permissions. The current version remains experimental; reliable
  end-to-end recording and desktop compatibility are not yet established.

## Audience and value

- **Audience:** Debian and Linux desktop users who want a focused screen and
  voice recorder.
- **Value proposition:** A small, native desktop interface rather than a
  multi-purpose production suite.
- **Positioning:** Not a streaming, editing, webcam, or collaboration service.

## Verified project details

- **Current GitHub release:** 0.2.1
- **License:** MIT
- **Languages / UI:** Python, GTK 4 and Libadwaita
- **Capture components:** FFmpeg, GStreamer/PipeWire, and PulseAudio-compatible
  input; end-to-end operation is not verified.
- **Wayland:** ScreenCast portal capture is implemented, but has not yet been
  validated on GNOME or KDE.
- **Compatibility:** Debian 12 and 13 are targets. Only a Debian 13 build,
  package dependency simulation, and GTK-window smoke check have been done.
- **Repository:** <https://github.com/sheriffhomard/DeskRecordor>
- **Issues:** <https://github.com/sheriffhomard/DeskRecordor/issues>
- **Releases:** <https://github.com/sheriffhomard/DeskRecordor/releases>
- **Authentic application screenshots:** none published yet; see
  [SCREENSHOTS.md](SCREENSHOTS.md).
