# Roadmap

Milestones below distinguish released prototypes from future work. A release
number does not mean every planned product feature is complete.

| Milestone | Scope | Status |
|---|---|---|
| 0.1 | Initial Python scaffold and state model | Released |
| 0.2 | GTK prototype, early capture adapters, initial Debian package | Released; experimental |
| 0.3 | Validate XDG portal and PipeWire lifecycle; real audio meter; robust pause/resume, finalization and recovery | In progress |
| 0.4 | Debian packaging polish and validation on supported desktop environments | Planned |
| 1.0 | Stable, end-to-end tested screen and microphone recording workflow | Planned |

Portal and PipeWire capture paths are implemented, but remain subject to testing
on actual Debian desktop sessions. Debian 12/13 and Wayland desktop compatibility
are not yet established.
